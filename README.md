# PhysX3D Physics Engine

Высокопроизводительный 3D физический движок на C++20.

## Возможности
- ✅ Rigid Body Dynamics
- ✅ Collision Detection (Sphere, Box, Capsule)
- ✅ BVH оптимизация
- ✅ Constraints система
- ✅ Многопоточность

## Компиляция

mkdir build && cd build
cmake ..
make -j$(nproc)
./physics_demo

text

## Система
- C++20 (GCC 15.2.1+)
- CMake 3.20+
- Arch Linux
